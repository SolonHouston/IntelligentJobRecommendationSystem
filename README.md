# 智能职位推荐系统

本科毕业设计项目，计划使用 Vue 3、Spring Boot 3 和 MySQL 8 构建职位推荐与站内招聘系统。

## 当前状态

目前处于 S0 契约与工程准备阶段。`backend/` 和 `frontend/` 尚未实现；`contracts/samples/` 中的职位均为本人编写的模拟数据，不能当作真实招聘信息。

## 目录

- `backend/`：Spring Boot 后端工程（待创建）。
- `frontend/`：Vue 前端工程（待创建）。
- `contracts/`：数据字段、推荐规则、状态权限和模拟样本。
- `docs/`：设计基线、研究报告、开发指导与开发记录。

## 两台电脑协作

开始开发前运行 `git pull`；完成一段可检查的修改后运行 `git add`、`git commit` 和 `git push`。本仓库公开，提交前检查是否包含个人信息、简历、真实招聘数据、凭据或本机配置。

项目技术选择见 `docs/实施选择.md`，具体开发路线见 `docs/总体开发实施蓝图_V2.md`。文档中的规划不代表功能已经实现。
